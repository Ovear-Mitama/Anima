编辑器使用教程

Anima 的编辑器是编排编辑器（剪映式多轨时间线，把入场 / 逐字 / 粒子 / 出场编成一段演出），世界内以浮窗形式打开。 这一页讲怎么用它。

打开方式#

方式说明
F7默认快捷键（可在「按键设置」里改）。世界里直接开成浮窗，世界继续渲染，边看边调。
Mod Menu模组列表 → 「Anima｜赋灵」→ 配置按钮，打开编排编辑器（Mod Menu 是可选的）。
代码AnimaApi.openTimelineEditor(parent)（编排编辑器）或 openClipEditor(parent, clips, onSave)（剪辑编辑器，结果在关闭时回传）。

配置世界#

编辑器里的预览是真实世界里的 3D 文字，在专用沙盒世界 anima-config 里效果最好。 界面上没有进世界的按钮：需要时用代码 AnimaApi.isConfigWorld() 判断、 AnimaApi.enterConfigWorld(parent) 进入（不存在会自动创建）：

  • 超平坦 + 单层地面，旁观模式、和平难度、时间固定，不会有怪也不掉出去；
  • 进去之后按 F7 开关编辑浮窗；
  • 它和你的正常存档互不影响，随时可以退出去。
门槛提示由调用方自己写：本库不再提供「请先进入专用世界」的提示页。需要强制玩家进世界的模组， 在打开编辑器前自己判断 isConfigWorld() 并给出提示即可（例如 Damage-Engine 就自己写了一个）。

界面布局#

编排编辑器由四个区域组成，调色板与属性面板拖标题栏就能移动，时间线拖它左边那列按钮区域移动：

区域位置作用
效果/粒子 调色板左上角入场 / 出场 / 粒子 / 已存粒子组，拖到时间线即可添加
预览中间世界里实时渲染的 3D 文本，播放头移动时会跟着变
属性面板右上角跟着当前选中的东西切换内容
多轨时间线底部播放 / 重头 / 清空 + 轨道区 + 标尺
世界里的坐标轴：选中物体后，它的位置处会出现一根三色坐标轴，拖轴就能沿该轴移动。 正对相机的那根轴会收缩隐藏（和 Blender / Unity 一样），避免出现没有意义的「斜线」。

效果/粒子 调色板#

  • 分类折叠：点分类标题（入场 / 出场 / 粒子 …）可展开收起，标题左边是 - / +。
  • 拖拽添加：把条目按住拖到时间线的某一轨上松手，就新增了一条动画。
  • 已存粒子组：你保存过的粒子组 JSON 会作为独立分类出现，直接拖进去就能复用。
预设分类说明
淡入入场整段文字透明度 0 → 1
打字入场入场逐字出现
下落 / 随机下落入场每个字从上方掉到目标位置（随机下落错开时间）
飘入入场像树叶一样从左上飘进来，逐字带旋转
淡出 / 打字出场出场淡出 / 逐字消失
+ 自定义粒子粒子新增单个粒子，再在属性面板选粒子与参数

时间线#

操作效果
拖动画条中间左右移动 / 上下换轨，自动吸附，同一轨不会重叠
拖动画条左右两端的绿条改变这条动画的时长
拖时间线空白处拖动播放头（跳时间）
滚轮上下翻看轨道
Ctrl + 滚轮缩放时间轴（以光标处为锚点）
右键动画条菜单：复制 / 创建组 / 删除
Delete删除选中条目
拖时间线右边缘调整时间线窗口宽度
  • 入场类（淡入、打字入场、下落、随机下落、飘入）自动锁在时间线开头；出场类（淡出、打字出场）自动锁在末尾，不会因为拖动而跑掉。
  • 时间线长度 = 文本时长：由右侧属性面板的「文本时长」决定（最小 0.01s），动画条不会超出它。
  • 最上面那条是文本对象轨道，上面画的是文本关键帧（◆）。

属性面板#

面板内容跟着你选中的东西走，不会把不相干的属性混在一起：

当前选中面板显示
文本对象（不选任何条）位置 X/Y/Z、缩放、透明度、文本时长、距离缩放开关
某个动画条时间线名称、速度×、动画时长、移除该条
单个粒子粒子注册名、数量、散布 X/Y/Z、速度、导入指令、偏移 X/Y/Z
粒子组＋添加粒子 / 导入指令 / 保存组 JSON，外加组自身的偏移 X/Y/Z
组内子粒子粒子注册名、数量、散布 X/Y/Z、速度、起始、时长、移除该粒子
输入框：都是「下划线」风格，直接点进去改数值即可；改完的值会写进这条动画的参数里。

文本关键帧#

选中文本对象（点时间线空白处取消选中任何条）时，属性面板里的位置 / 缩放 / 透明度是按关键帧插值的：

  1. 把播放头拖到想要的时间点；
  2. 点该属性行右边的 ◆ 按钮，就在当前播放头处打一个关键帧（当前值会被快照下来）；
  3. 修改输入框里的值，会自动写入播放头处的那个关键帧（没有就新建）；
  4. 文本对象轨道上的白色菱形就是关键帧，拖它可以改时间，右键或选中后按 Delete 删除。
一次关键帧记录全部属性：位置、缩放、透明度是同一个关键帧上的四个通道，所以拖动菱形会同时改变它们的时间点。

距离缩放#

  • 开：真实透视，离得远字就小（近大远小）。
  • 关：无论多远，看起来大小都一样（适合做 UI 式的世界标签）。

单个粒子#

从调色板拖 + 自定义粒子，或右键已有动画条 → 创建组。选中粒子后，属性面板里可以改：

字段含义（与原版 /particle 一致）
粒子注册名注册表 id，例如 minecraft:flame；点右侧 ▾ 可从列表里挑（可搜索）
数量这条动画总共发射多少个粒子（不是每帧）
散布 X/Y/Z粒子的随机散布范围
速度初速度倍率
偏移 X/Y/Z相对锚点的位置偏移，跟文本位置是分开的
参数化粒子不支持：dust / block 这类需要额外参数的粒子无法直接发射，属性面板会提示「未知粒子」。

指令导入#

点属性面板里的「导入指令」，把原版指令整段粘进去，会自动拆成粒子名 + 数量 + 散布 + 速度：

粘贴示例
/particle minecraft:flame ~ ~ ~ 0.2 0.2 0.2 0.05 20
  • 结尾的 20 是数量，前面三个小数是 delta（散布），再前面那个是 speed；
  • 解析失败会提示缺少哪一段（粒子名 / 位置 / delta / speed / count）。

粒子组#

右键一个粒子动画条 → 创建组，就得到一个粒子组。一个组里可以放多个粒子，每个粒子有自己的注册名、数量、散布、速度，以及自己的起始与时长。

  • 组在时间线上用 - / + 展开成子行，每个子粒子一行；
  • 组被拖动 / 改长度时，子粒子始终被夹在组的范围内；
  • 保存组 JSON：把整组导出到 config/anima/particle_groups/，之后会出现在调色板的「已存粒子组」里，也可以直接把 JSON 发给别人导入。

组内子粒子#

把组展开后在时间线上点某个子行，属性面板就会切到这个子粒子自己的参数（而不是整组的）：

  • 粒子注册名：可以直接在输入框里改，或点右侧 ▾ 打开粒子列表挑；
  • 数量 / 散布 X/Y/Z / 速度：这个子粒子独立生效；
  • 起始 / 时长：它在组时间轴里的位置与长度，也可以直接在时间线上拖子行两端的绿条；
  • 移除该粒子：只删这一个子粒子。

保存到哪里#

路径内容
config/anima/animations/动画编辑器保存的定义（覆盖资源包同 id 定义）
config/anima/particle_groups/保存 / 分享的粒子组 JSON
config/anima/timelines/导出的时间线 JSON

从旧名字（texture-animation-library）升级时会自动迁移这些目录，配置不会丢。
