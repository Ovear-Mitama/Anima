Anima｜赋灵

Minecraft 1.21.1 的客户端动画库 / 动画工作台。给 GUI 贴图、世界内精灵、文本加关键帧动画， 并在游戏里用一条剪映式多轨时间线把它们编成完整的演出。

这是什么#

Anima 同时服务两类人：资源包 / 整合包作者用 JSON 就能定义动画；模组开发者用一套 Java API 画出动画贴图、动画文本、真 3D 世界文字、真实 3D 粒子与「贴图拼字」。

所有逻辑都在客户端运行，服务端不需要安装。Fabric 与 NeoForge 共用同一份 common/ 源码， 许可 Apache-2.0。

能做什么#

能力说明
资源包 JSON 动画四种类型：gui_sprite / gui_dynamic / world_sprite / text，配 6 种内置特效与 30+ 缓动曲线。见 资源包 JSON 动画。
游戏内可视化编辑器左侧拖特效、中间实时预览、右侧调属性、底部多轨时间线；F7 打开。见 编辑器使用教程。
逐字动画打字入场 / 出场、下落、随机下落、飘入——每个字有独立的位移、缩放、旋转、透明度。
真 3D 世界文字真实透视、会被方块遮挡、可开关距离缩放；也能投影到 HUD 层保持像素大小。
粒子按注册表 id 发射原版 / 其它 mod 的粒子，支持 /particle 语义的数量与散布；可在编辑器里把多个粒子组编成「粒子组」并导出分享。
贴图拼字把一张图片按格子切开当字形（SpriteText），用来做伤害数字这类「纹理数字」。
开发者 API统一门面 anima.api.AnimaApi，覆盖绘制、特效、缓动、挂钩与编辑器入口。见 Java API 教程。

源码结构#

目录
texture-animation-library/
├── common/
│   ├── src/main/java/anima/        # 引擎、特效、缓动、动画定义（双端共用）
│   └── src/client/java/anima/      # 渲染、API、编辑器界面（仅客户端）
│       ├── api/AnimaApi.java       # ★ 对外 API 门面
│       ├── client/gui/             # 编辑器界面
│       ├── client/world/           # 3D 文字 / 粒子 / 投影
│       └── manager/                # 动画定义管理器 + 配置读写
├── src/                            # Fabric 入口 + 资源
└── neoforge/                       # NeoForge 入口 + 资源

安装#

  1. 把对应加载器的 anima-*.jar 放进 .minecraft/mods/。
  2. Fabric 端需要先装 Fabric API；Mod Menu 可选（装了会在模组列表里多一个配置入口）。
  3. 只有客户端需要装；服务端装不装都不影响功能。

从源码构建#

目标命令产物
Fabric./gradlew buildbuild/libs/
NeoForgecd neoforge && ./gradlew buildneoforge/build/libs/
需要：JDK 21。Windows 下把 ./gradlew 换成 gradlew.bat。

开发运行#

终端
# Fabric 客户端
./gradlew runClient

# NeoForge 客户端
cd neoforge && ./gradlew runClient

打开编辑器#

方式说明
F7（可改键）已经在世界里 → 直接开成浮窗；不在世界里 → 先带你进入配置世界，进去后按 F7 开关浮窗。
Mod Menu模组列表 → 「Anima｜赋灵」→ 配置按钮。
代码调用AnimaApi.openTimelineEditor(parent) / AnimaApi.openAnimationEditor(parent)

第一条动画#

  1. 按 F7 进入编辑器（不在世界里时会先创建并进入 anima-config 配置世界）。
  2. 从左上的「效果/粒子」里把 淡入 拖到下方时间线上。
  3. 再拖一个 打字入场，它会自动锁在时间线开头（入场类动画固定贴左边）。
  4. 点时间线空白处拖动播放头，中间的预览会实时跟着变。
  5. 要粒子就拖「+ 自定义粒子」，再在右侧属性面板里填数量 / 散布 / 速度。
  6. 选中时间线上的条，按 Delete 删除；右键有复制 / 创建组 / 删除菜单。
