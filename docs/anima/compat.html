模组文档

兼容性与 FAQ

渲染 mod、资源包优先级、联机、性能，以及一些容易踩的坑。

渲染相关#

环境情况
Sodium / Sodium Extra 兼容。GUI / HUD 层的绘制完全不受影响；世界内精灵帧序列是通过向资源栈注入 .png.mcmeta 实现的，和原版共用同一条 atlas 管线。
Iris / 光影 兼容。理由同上：动画元数据走的是原版纹理管线，不额外插渲染 pass。
其它 GUI / HUD mod Anima 只在被调用时绘制，不抢占任何全局渲染阶段，正常共存。
真 3D 世界文字 用的是原版字体渲染 + 相机的姿态矩阵，因此有正常的透视与深度遮挡，也跟随 FOV / 缩放设置。

资源包与优先级#

  • 注入位置：Anima 生成的动画元数据位于资源栈顶层，因此会覆盖低优先级资源包对同一张纹理的动画定义。
  • 配置覆盖：config/anima/animations/ 里的定义优先于所有资源包；想恢复资源包原定义，在动画编辑器里点「删除/重置」。
  • 重载：world_sprite 的改动要在 F3+T 之后生效，与原版动画一致。

服务端#

  • Anima 的功能全部在客户端运行，服务器上可以不装；装了也只是多注册一次引擎，没有任何副作用。
  • 联机时客户端各装各的即可，不会因为服务端没有 Anima 而失效。
  • 库自身不发送任何网络包。

常见问题#

按 F7 没反应 / 直接进了另一个世界？

这是因为编辑器需要真实世界渲染：如果你在主菜单（不在存档里），Anima 会先把 anima-config 配置世界建好并把你带进去， 进去之后再按一次 F7 就会弹出编辑浮窗。这个沙盒世界与你的存档互不影响。

编辑器里没有字，只有坐标轴？

  • 确认在世界里（浮窗模式），中间区域在完整界面模式下才会画预览画布；
  • 检查属性面板里透明度是不是被调到了 0；
  • 视角可能正对着文字的背面 —— 用 WASD 或右键拖动绕一圈看看。

坐标轴拖不动 / 某根轴不见了？

正对相机的那根轴会收缩并隐藏（避免出现方向没有意义的斜线），转一下视角它就会回来。另外坐标轴只在世界的浮窗预览里可用。

改了属性，时间线长度也跟着变了？

时间线长度只由「文本时长」决定：它等于你手动填的值，或者最靠后的那个文本关键帧的时间，都没有时用 3 秒兜底。 改某一条动画的时长不会改变整条时间线，动画条会被夹在时间线内。

粒子设了 1 个却像一直在刷？

「数量」是这条动画整段要发射的总数（1 = 只发一个），不是每帧的数量。如果数量被改大，前面已经发射过的部分不会重复补发。

dust / block 这类粒子发不出来？

它们需要额外参数（颜色 / 方块状态），目前不支持，属性面板会提示「未知粒子」。用不带参数的粒子代替即可。

动画触发了但只动一下就不动了？

标签式自动动画只支持循环型特效（blink / pulse / shake / 循环淡入淡出）。 一次性的淡入或位移请用显式 API（drawHudText / drawWorldText3D），并且每次触发新建一个实例。

想用别的语言 / 改界面文字？

编辑器界面自带中文与英文（assets/anima/lang/zh_cn.json、en_us.json）。 在资源包里放一份同 key 的 <语言代码>.json 就能覆盖（key 以 anima.ui. 开头）。

能从旧版本升级吗？

可以。模组改名为 Anima 之后，从 texture-animation-library 时期的配置目录会自动迁移， 已保存的动画、时间线、粒子组都不会丢。

性能与开销#

  • 动画计算是纯算术，没有额外分配；不订阅事件时开销为零。
  • 只在被调用 / 被绘制时才工作：不做全局的每帧遍历，也不 hook 渲染管线。
  • 世界内精灵用的是原版动画机制，性能特征与材质包动画相同。
  • 编辑器本身只在打开时消耗资源（含实时的世界预览渲染）。
