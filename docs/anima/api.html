模组文档

Java API 教程

给模组开发者的一站式入口：anima.api.AnimaApi。 它把库内部的能力按用途聚合起来，全部都是薄封装，不改变语义。

引入与依赖#

  • 包基础：anima；下面所有示例都针对客户端。
  • Fabric 与 NeoForge 共用同一套 API，平台差异（世界渲染事件、客户端 tick、资源重载）由库内部的 PlatformHooks 处理。
  • API 只在客户端存在，请在客户端入口（Fabric 的 ClientModInitializer / NeoForge 的客户端事件）里调用。

真 3D 世界文字#

画出来的字真的在世界里：有透视、会被方块遮挡、会随视角变化 —— 适合伤害跳字、世界锚定的提示。 必须在世界渲染回调里画（相机变换已经在 pose 里了）：

MyModClient.java
import anima.api.AnimaApi;

public final class MyModClient {

    public static void init() {
        AnimaApi.onWorldRender((pose, buffers, camera, partialTick) -> {
            // 在 (x, y, z) 处画一串 3D 文字
            AnimaApi.drawWorldText3D(buffers, camera, "1234",
                x, y, z, 0xFFFFFFFF, 0.02f, null);
        });
    }
}
参数说明
buffers / camera回调里给你的那两个，原样传进来即可
worldScale1 个 GUI 像素 = 多少个方块。数值越大字越大，参考 WorldText3D.DEFAULT_SCALE（0.025）
RenderModifier位移 / 缩放 / 透明度，可传 null（等价于不修改）
想要「远近一样大」：用 drawWorldTextHud(...)，它把世界坐标投影到 HUD 层绘制，像素大小固定，但就没有遮挡与透视了。
不想被生物挡住：用带 seeThrough 参数的 drawWorldText3D(..., glyphs, true) 重载 —— 它改用 see-through 文字渲染类型（不做深度测试）， 文字不会被方块或实体遮挡，始终盖在世界之上。伤害跳字就用的这个。

逐字动画#

每个字符单独给位移 / 缩放 / 旋转 / 透明度，就能做出打字、下落、飘入这类效果：

Glyphs.java
WorldText3D.Glyph[] glyphs = new WorldText3D.Glyph[text.length()];
for (int i = 0; i < text.length(); i++) {
    WorldText3D.Glyph g = new WorldText3D.Glyph();
    g.dx = 0f;          // 相对锚点的像素位移
    g.dy = -12f * (1f - progress);
    g.scale = 0.6f + 0.4f * progress;
    g.rot = rot;        // 弧度
    g.alpha = progress;
    glyphs[i] = g;
}

// 带逐字变换的重载
AnimaApi.drawWorldText3D(buffers, camera, text, x, y, z, 0xFFFFFFFF, 0.02f, glyphs);
不想自己算？在编辑器里把入场 / 逐字动画排好，导出时间线 JSON（config/anima/timelines/），直接拿里面的参数用。

HUD 文本动画#

两种玩法：标签式（自动生效）与显式绘制（自己控制时钟，适合每颗伤害数字单独计时）。

Hud.java
import anima.text.TextAnimations;

// 1) 标签式:Font Mixin 全局拦截,任意组件都能动
guiGraphics.drawString(font,
    TextAnimations.parse("<anim:blink>暴击!</anim>"), x, y, 0xFFFFFFFF);
TextAnimations.withTag(component, "blink");   // 或给已有组件打标签

// 2) 显式:自己控制本地时钟与时长(每颗跳字独立计时)
TextAnimationSpec spec = AnimaApi.textSpec("damage");
AnimaApi.drawHudText(g, font, Component.literal("42"),
    x, y, 0xFFFFFFFF, spec, localMs, 1000f);

// 3) 世界锚定但画在 HUD 层(像素大小固定)
AnimaApi.drawWorldTextHud(g, font, "42", wx, wy, wz,
    0xFFFF5555, spec, localMs, true);   // 最后一个是是否带阴影

// 4) 跳字:世界坐标 + 调用方算好的屏幕像素偏移(随机散布/漂移) + 缩放/透明度倍率
AnimaApi.drawWorldTextHudOffset(g, font, Component.literal("42"),
    wx, wy, wz, offX, offY, 0xFFFF5555, spec, localMs, 4300f, true, 1.0f, 0.8f);
方法什么时候用
drawHudText(...)屏幕固定位置的自绘数字 / 文本（会返回绘制宽度）
drawWorldTextHud(...)跟着世界坐标走、但保持像素大小（不可见时返回 false）
drawWorldTextHudOffset(...)世界坐标 + 自己算好的屏幕像素偏移（随机环半径 / 漂移），外加缩放与透明度倍率；支持 Component，粗体等样式不会丢
保留命名空间：标签是用 Style 的 font 字段承载的（anima:textanim/<tag>）， 所以 anima:textanim/* 不能用作真实字体名，标记也会覆盖组件原来的 font。用自定义字体的组件请走显式绘制。

粒子#

参数语义和原版 /particle 一致：count 是总数，delta 是散布范围，speed 是初速度倍率。

Particles.java
// 一次性发射 20 个火焰粒子,散布 ±0.2,速度 0.05
AnimaApi.emitParticles("minecraft:flame", x, y, z, 20, 0.2, 0.2, 0.2, 0.05);

// 发射前可以先问一句能不能用(dust / block 这类参数化粒子返回 false)
if (AnimaApi.isParticleSupported("minecraft:flame")) {
    // ...
}

粒子按注册表 id发射，原版和别的 mod 注册的粒子都能用。

贴图拼字#

把一张图按固定格子切开当字形（charset 的第 i 个字符用第 i 格），用来做「纹理数字」：

SpriteNumbers.java
ResourceLocation tex = ResourceLocation.fromNamespaceAndPath(
    "damage_engine", "textures/font/digits.png");

// 按 8x12 切格,第 0..9 格分别是 0..9
SpriteText.Atlas digits = AnimaApi.spriteAtlas(tex, 8, 12, "0123456789");

// 画出来(可以顺手套一个动画修饰符)
AnimaApi.drawSpriteText(guiGraphics, digits, "88", x, y, 0xFFFFFFFF, modifier);

也可以从 JSON 读图集：{ "texture", "cell_width", "cell_height", "columns", "charset", "scale" } → spriteAtlasFromJson(json)。

绘制动画贴图#

资源包 JSON（或代码注册）定义好的动画贴图，一行就能画出来；需要独立计时就建实例：

Textures.java
AnimatedTextureManager manager = AnimatedTextureManager.get();

// 1) 走全局时钟,一行画完
manager.drawAnimated(guiGraphics, id, x, y, w, h);

// 2) 每个实例独立计时(例如每次爆炸新建一个)
AnimatedGuiSprite sprite = manager.createGuiInstance(id);
sprite.draw(guiGraphics, x, y, w, h, AnimationEngine.get().globalTimeMs());

// 3) 世界内精灵帧序列(下次 F3+T 资源重载后生效)
manager.registerWorldSprite(spriteId,
    new WorldSpriteAnimationSpec(new int[]{0, 1}, 250, false));

注册特效 / 缓动 / 动画#

Register.java
// 特效:两种注册方式
AnimaApi.registerEffect("my_effect", json -> new MyEffect());  // 工厂:按 JSON 配置造实例
AnimaApi.registerEffect("my_fixed", myFixedEffect);           // 固定实例:忽略 JSON

// 缓动:注册后 JSON 里就能写 "ease": "my_ease"
AnimaApi.registerInterpolator("my_ease", t -> t * t);

// 文本动画规格:用代码组合特效
AnimaApi.registerTextTag("my_tag", AnimaApi.specOf(myEffect));

// 动画定义:构建器 or 直接读资源包格式的 JSON
AnimaApi.registerAnimation(
    AnimaApi.animation(id, AnimationType.GUI_SPRITE)
        .texture(tex).addFrame(0, 0, 16, 16).frameTimeMs(200).loop(true)
        .build());
AnimaApi.registerAnimation(AnimaApi.animationFromJson(id, jsonObject));

挂钩与工具#

方法说明
onWorldRender(hook)每帧世界渲染回调；hook.render(pose, buffers, camera, partialTick)
onClientTick(runnable)客户端 tick 回调（推进自己的动画时钟很方便）
onClientReload(id, listener)资源重载（F3+T）回调
projectToScreen(x, y, z)返回 {screenX, screenY, w}，相机背后返回 null

导出时间线#

编辑器排好的时间线可以导出成 JSON，交给别的 mod 或做二次处理：

Export.java
String path = AnimaApi.exportTimeline(timelineJson);
// → config/anima/timelines/

想直接给玩家打开编辑器，用 AnimaApi.openTimelineEditor(parent)（编排 / 时间线；Mod Menu 入口用的就是它）， 或 openClipEditor(parent, clips, textProps, previewText, onSave)：载入调用方给的剪辑、文本属性与 预览文本（传 null 就用库自己的示例）， 关闭时把两者一起回传（ClipEditorResult.clips() / textProps()；后者用 AnimaApi.evalTextProps(props, localMs) 求值成 {dx,dy,dz,scale,alpha}，dx/dy/dz 是方块位移）。编辑器本身没有保存按钮，落盘由调用方决定。

剪辑编辑器里的预览用真实世界渲染器才好看。想要求玩家先进专用配置世界，用自己的界面写门槛即可： AnimaApi.isConfigWorld() 判断，AnimaApi.enterConfigWorld(parent) 进入（不存在会自动创建）。
