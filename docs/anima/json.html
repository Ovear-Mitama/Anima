资源包 JSON 动画

不用写任何代码：把 JSON 丢进资源包，就能给 GUI 贴图、世界内精灵、文本加上关键帧动画。

放在哪里#

  1. 在资源包里创建目录 assets/<你的命名空间>/texture_animations/；
  2. 把每个动画写成一个 .json 文件，文件名就是定义 id 的路径；
  3. 进游戏按 F3+T 重载资源即可生效。

定义 id 的规则是 <命名空间>:<文件名>，例如 assets/damage_engine/texture_animations/rating_star.json → damage_engine:rating_star。

也可以放进配置目录：编辑器保存的定义会写到 config/anima/animations/，格式完全相同，且优先级高于资源包。两种来源可以混用。

四种类型#

type作用关键字段
gui_sprite GUI / HUD 贴图的帧序列，帧从一张精灵表里按 UV 区切 texture、texture_width / texture_height、frames、frame_time
gui_dynamic 多张独立图片拼成的动态纹理（每帧一张图） frame_textures
world_sprite 世界内精灵的帧序列（注入 .png.mcmeta，Sodium / Iris 下同样安全） texture（精灵 id）、frame_indices、frame_time、interpolate
text 文本动画标签，配合 <anim:标签> 或 API 使用 effects

完整示例#

一张 32×16 的精灵表，切成两帧 16×16，每 200ms 切一帧，并叠加 600ms 周期的闪烁：

assets/damage_engine/texture_animations/rating_star.json
{
  "type": "gui_sprite",
  "texture": "damage_engine:textures/gui/rating/star.png",
  "texture_width": 32,
  "texture_height": 16,
  "frames": [[0, 0, 16, 16], [16, 0, 16, 16]],
  "frame_time": 200,
  "loop": true,
  "effects": [
    { "type": "blink", "period": 600, "min_alpha": 0.2, "max_alpha": 1.0 }
  ]
}

通用字段#

字段默认说明
typegui_sprite四种类型之一，见上
looptrue是否循环播放帧序列
play_modelooploop / once / pingpong
frame_time—每帧毫秒数
interpolatefalse仅在 world_sprite 下有意义，是否做帧间插值
effects[]特效数组，可叠加多个，见下

内置特效#

写在 effects 数组里，可以同时叠多个；括号内为默认值。

type参数（毫秒）说明
fadefade_in(200) hold(0) fade_out(200) loop(false)淡入 → 保持 → 淡出
blinkperiod(500) min_alpha(0.1) max_alpha(1.0)正弦波周期闪烁
pulseperiod(800) min_factor(0.5) max_factor(1.0) color[r,g,b]周期性的颜色 / 亮度脉冲
shakeamplitude(3) frequency(12) duration(300) decay(false)抖动 / 晃动，decay 打开会逐渐衰减
slidefrom[x,y] to[x,y] duration(300) ease("linear") loop(false)位移，支持缓动曲线
scalefrom(1) to(1) duration(300) ease("linear") loop(false)缩放，支持缓动曲线

缓动曲线#

slide / scale 的 ease 字段可选下列名字（区分大小写）：

  • 两个基础值：linear、step
  • 曲线族：Quad、Cubic、Quart、Quint、Sine、Expo、Circ、Back、Elastic、Bounce
  • 方向前缀：easeIn / easeOut / easeInOut

拼起来就是完整名字，例如 easeOutCubic、easeInOutBounce、easeInBack。也可以自己注册（见 Java API · 注册特效 / 缓动 / 动画）。

文本动画标签#

定义 type: "text" 的动画后，就可以用标签让任意文本自动动起来：

MyScreen.java
// Font Mixin 会全局拦截,聊天 / 按钮 / HUD 任意文本都能用
guiGraphics.drawString(font, TextAnimations.parse("<anim:blink>暴击!</anim>"), x, y, 0xFFFFFFFF);

// 或者给已有组件打标签
TextAnimations.withTag(component, "blink");
保留命名空间：标签是通过 Style 的 font 字段承载的（anima:textanim/<标签>）， 所以 anima:textanim/* 不能用作真实字体名，标记也会覆盖组件原本的 font 字段。 自定义字体的文本请改用显式绘制 API。

注意事项#

  • 重载：world_sprite 的改动要在下一次资源重载（F3+T）后才生效，和原版动画一样。
  • 包优先级：Anima 注入的动画元数据位于资源栈顶层，会盖住低优先级资源包对同一张纹理的动画定义。
  • 一次性特效：标签式自动文本只支持循环型特效（blink / pulse / shake / 循环淡入淡出）。 一次性的淡入或位移请用显式 API，每次触发新建实例。
  • 定义 id 不要重复：同名定义后加载的会覆盖先加载的。
