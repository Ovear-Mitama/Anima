Damage Engine API

为其他模组提供的扩展接口。当前包含评分 API（加分项），后续将持续划分并扩展更多 API。

简介#

通过注册一个 BonusProvider，让其他模组的自定义规则参与 Damage Engine 的评分（Rating）计算——加分条件由你自己的模组定义。

Damage Engine 只负责在每次命中时回调所有已注册的加分项并累加返回值，具体在什么条件下加分、加多少分，完全由你的模组决定。

提示： API 位于 damage.engine.api 包，Fabric 与 NeoForge 通用，注册方式完全一致。

前置条件#

适用于 Damage Engine 1.4.7+（含）。

快速开始#

  1. 在你的模组初始化阶段引入 damage.engine.api.DamageEngineApi。
  2. 调用 DamageEngineApi.registerBonusProvider(...) 注册加分项。
  3. 每次命中时，Damage Engine 会回调你的 bonusOnHit(...)，返回值即为该次命中增加的分数。
  4. 打开配置界面 → 评分 → 其他mod加分项，可看到已注册的加分项列表。

添加依赖

将 Damage Engine 作为编译期依赖（按你使用的发布渠道替换坐标）：

build.gradle
dependencies {
    // 若通过 Maven 发布，替换为实际坐标
    modImplementation "damage.engine:damage-engine:1.4.7"
    // 或者直接引用本地 jar
    // modCompileOnly files("libs/damage-engine-1.4.7.jar")
}
建议： 加分项 API 只在运行时生效，推荐使用 compileOnly / modCompileOnly，并在 fabric.mod.json / neoforge.mods.toml 中声明可选依赖。

注册加分项#

最小示例：单次伤害 ≥ 100 时额外 +50 分。

ExampleMod.java
import damage.engine.api.DamageEngineApi;

public final class ExampleMod {
    public static void init() {
        DamageEngineApi.registerBonusProvider(new DamageEngineApi.BonusProvider() {
            @Override
            public String id() {
                return "example_mod:heavy_hit";
            }

            @Override
            public String displayName() {
                return "重击额外加分";
            }

            @Override
            public float bonusOnHit(DamageEngineApi.Hit hit, DamageEngineApi.SessionStats session) {
                return hit.damage() >= 100f ? 50f : 0f;
            }
        });
    }
}

API 参考#

DamageEngineApi

方法说明
static boolean registerBonusProvider(BonusProvider provider) 注册一个加分项。同一 id() 只注册一次，重复注册会被忽略并返回 false。
static List<BonusProvider> getBonusProviders() 返回当前已注册的全部加分项（只读）。

DamageEngineApi.BonusProvider

方法说明
String id()唯一标识，建议使用 命名空间:路径 形式；用于去重与界面展示。
String displayName()在配置界面“其他mod加分项”中展示的名称。
float bonusOnHit(Hit hit, SessionStats session)每次命中时计算加分；返回 0 或负数表示不加分。

DamageEngineApi.Hit

成员类型说明
damage()float本次命中造成的伤害
crit()boolean本次命中是否被判定为暴击

DamageEngineApi.SessionStats

成员类型说明
comboCount()int当前连击数
hitCount()int命中次数（含暴击）
critCount()int暴击次数
totalDamage()float本次评分会话的累计伤害

完整示例#

条件完全自定义：连击 ≥ 5 的暴击额外加分，且对单次高额伤害追加奖励。

MyBonus.java
import damage.engine.api.DamageEngineApi;

public final class MyBonus {

    public static void register() {
        DamageEngineApi.registerBonusProvider(new DamageEngineApi.BonusProvider() {

            @Override
            public String id() {
                return "mymod:combo_crit";
            }

            @Override
            public String displayName() {
                return "连击暴击奖励";
            }

            @Override
            public float bonusOnHit(DamageEngineApi.Hit hit, DamageEngineApi.SessionStats session) {
                float bonus = 0f;

                // 条件 1：连击 ≥ 5 且本次为暴击
                if (session.comboCount() >= 5 && hit.crit()) {
                    bonus += 15f;
                }

                // 条件 2：本次伤害超过 50
                if (hit.damage() > 50f) {
                    bonus += 10f;
                }

                // 条件 3：整场累计伤害达到阈值后额外奖励
                if (session.totalDamage() >= 500f) {
                    bonus += 25f;
                }

                return bonus;
            }
        });
    }
}

在游戏内查看#

打开配置界面（默认按键可在“按键”标签页查看），进入 评分 标签页， 展开“单次伤害大小加分”下方的 其他mod加分项：

  • 已注册的加分项会以 显示名 (id) 的形式列出；
  • 若没有任何模组注册加分项，该分组内会显示一行占位提示。

注意事项#

  • 幂等注册：id() 相同的加分项只注册一次，适合在模组初始化时无条件调用。
  • 异常隔离：单个加分项抛出异常不会影响整体评分，但请尽量保证实现健壮。
  • 调用次数：每次命中会对“每个已注册加分项”调用一次 bonusOnHit，请保持实现轻量。
  • 评分在客户端计算：加分项用于本地评分显示，请勿在其中执行昂贵的网络或世界操作。
  • 条件自定义：Damage Engine 只负责在命中时回调并累加返回值，具体加分规则完全由你的模组实现。
